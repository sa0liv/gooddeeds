# GoodDeeds

Projeto desenvolvido para a disciplina de Engenharia de Software.

## 💡 Sobre o projeto

O GoodDeeds é uma plataforma web que conecta voluntários a eventos sociais.

## 🚀 Tecnologias

- Frontend: React + Vite
- Backend: Node.js + Express
- Versionamento: GitHub
- Prototipação: Figma
- Gestão: Trello
